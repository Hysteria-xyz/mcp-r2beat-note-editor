=====================================================================
R2BEAT MCP SERVER - GUIA DE USO Y FUNCIONES
=====================================================================

Servidor MCP (Model Context Protocol) para generar charts nativos de
R2Beat/R2Note desde audio y descripciones en lenguaje natural.

Antes de usarlo, escribe:  pip install -r requirements.txt


=====================================================================
1) QUE ES Y COMO FUNCIONA
=====================================================================

- Tu asistente (OpenCode, Claude, etc.) habla con este servidor por stdio.
- El servidor mantiene "workspaces" de chart en memoria, identificados
  por un chart_id (el que tú elijas, p.ej. "cancion1").
- Generas el chart paso a paso: crear, añadir notas/patrones, validar,
  espejar, desplazar y guardar en un .xml compatible con R2Beat.

Formato de salida (idéntico a los charts reales del juego):

  <?xml version="1.0" encoding="gb18030"?>
  <TITLE Name="NombreCancion">
  <BPM Frame="0" BPM="175"></BPM>
  <BGM Name="carpeta/cancion.mp3" Volume="1.00"></BGM>
  <DELAY Value="0"></DELAY>
  <LENGTH Value="9000"></LENGTH>
  <AREA Coord="48" Kind="18" Level="2" FxSndIndex="0"></AREA>
  ...
  </TITLE>

Rejilla de tiempo:
  - 1 pulso (beat) = 12 coords
  - R2Beat va a 60 fps
  - coords por segundo = BPM / 5
  - Frame desde Coord a un BPM:  F = Coord * 300 / BPM
  - Coord desde Frame:            C = Frame * BPM / 300
  - DELAY es un ajuste en frames (offset de la primera nota).

Divisiones de nota aceptadas (notes por pulso -> paso en coords):
  division 1 = 12 coords (negra)         division 6 = 2 coords
  division 2 = 6 coords  (corchea)       division 8 = 1.5 coords
  division 3 = 4 coords  (tresillo)      division 12 = 1 coord (denso)
  division 4 = 3 coords  (semicorchea)

Tipos de nota y Kind/Level:
  singles:
    up=16/L3  down=17/L3  left=18/L2  right=19/L2
    up_left=20/L5  up_right=21/L5  down_left=22/L4  down_right=23/L4
    ramp=24/L4 (salto)  star_left=26/L1  star_right=27/L1
  holds (largas):
    up_left=128/129/130  up_right=131/132/133
    up=134/135/136  down=137/138/139  left=140/141/142  right=143/144/145
  Las holds duran mínimo 12 coords (1 pulso) y se construyen solas
  (inicio, notas intermedias cada 12 coords, fin).


=====================================================================
2) LAS 23 TOOLS DISPONIBLES EN EL SERVIDOR
=====================================================================

1. create_chart(chart_id, name, bpm=192.0, bgm="", volume=1.0, delay=0, length=0)
   Crea un workspace de chart vacío.

2. load_chart(chart_id, path)
   Carga un .xml de R2Beat existente en memoria.

3. get_chart(chart_id)
   Devuelve todos los datos del chart (metadata, tempos, todas las notas).

4. list_charts()
   Lista todos los charts en memoria con sus nombres, BPMs y cantidad de notas.

5. delete_chart(chart_id)
   Borra un chart de la memoria.

6. duplicate_chart(source_chart_id, new_chart_id)
   Clona un chart existente para crear otra dificultad (ej. Normal -> Hard).

7. set_metadata(chart_id, name=None, bgm=None, volume=None, delay=None, length=None)
   Modifica los metadatos del chart.

8. set_tempo(chart_id, frame, bpm, original_bpm=None)
   Añade o actualiza un cambio de tempo.

9. add_pattern(chart_id, start_coord, end_coord, division=4, note_types=None, strategy="alternate", seed=None)
   Coloca una sucesión de notas.
   Estrategias: alternate, sequence, pingpong, random, walk.

10. add_hold(chart_id, direction, start_coord, end_coord)
    Añade una nota larga con auto-ajuste a múltiplos de 12 coords y notas intermedias.

11. add_note(chart_id, note_type, coord)
    Añade una nota simple en una coordenada exacta.

12. shift_notes(chart_id, delta_coord, start_coord=None, end_coord=None)
    Desplaza las notas hacia adelante o atrás en el tiempo.

13. mirror_chart(chart_id, start_coord=None, end_coord=None)
    Espeja horizontalmente las notas (left <-> right, up_left <-> up_right, etc.).

14. scale_chart(chart_id, factor, origin_coord=0.0)
    Escala el espaciado entre notas para acelerar o ralentizar la canción.

15. analyze_audio(path)
    Analiza un mp3/wav (BPM, onsets, silencio inicial sugerido para DELAY).

16. onsets_to_notes(chart_id, audio_path, note_type="down", division=4, max_notes=500, offset_coord=0.0)
    Genera notas automáticamente sobre los golpes del audio.

17. remove_notes(chart_id, start_coord=None, end_coord=None)
    Borra notas en un rango o todas.

18. snap_chart(chart_id, division=4)
    Ajusta todas las notas a la rejilla indicada.

19. validate_chart(chart_id)
    Comprueba duplicados, niveles, holds bien cerradas y calcula dificultad (1 a 20 estrellas).

20. auto_fix_chart(chart_id)
    Corrige automáticamente duplicados, niveles y calcula la longitud exacta.

21. get_chart_summary(chart_id)
    Devuelve resumen métrico: estrellas de dificultad, NPS medio, NPS pico y conteos.

22. save_chart(chart_id, path)
    Guarda el archivo .xml en formato nativo con codificación gb18030.

23. write_music_entry(chart_id, music_txt_path, index=None, image=None, file=None, level=17, genre="Electronica", artist="", coin="0")
    Registra la canción en el rnr_script/music.txt.


=====================================================================
3) CLI DIRECTO (cli.py)
=====================================================================

Para realizar tareas directamente desde la terminal sin abrir el servidor MCP:
  python cli.py info mi_cancion.xml
  python cli.py validate mi_cancion.xml
  python cli.py mirror mi_cancion.xml mi_cancion_mirror.xml
  python cli.py shift mi_cancion.xml --coords 12
  python cli.py autofix mi_cancion.xml
